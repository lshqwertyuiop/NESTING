# NESTING

船舶型钢套料 WebCAM 本地展示版。

## 启动

需要 Python 3.10 或更高版本，以及 Edge、Chrome 等现代浏览器。程序使用 Python 标准库，无需安装 Python 第三方库或 Node.js。

### Windows

1. 下载并解压仓库，或使用 Git 克隆。
2. 双击根目录的「打开本地展示.cmd」。
3. 浏览器会自动打开本地页面。使用期间保持命令窗口运行，结束时在窗口内按 Ctrl+C。

默认地址为 http://127.0.0.1:8836/。也可以在项目根目录运行以下命令。

```powershell
python preview.py --port 8836
```

### macOS / Linux

在项目根目录运行以下命令。

```bash
python3 preview.py --port 8836
```

如果未自动打开浏览器，手动访问 http://127.0.0.1:8836/。

同一份程序已启动时，直接访问上面的地址即可。端口被其他程序占用时，可指定其他端口，但浏览器保存的已读标记和界面偏好按地址分别存储。

## 使用范围

- 零件资源支持船号、分段号、类型结构树，创建时间范围、区号和类型筛选，以及剩余可套数量校验。
- 支持按区号、按分段号演示套料，查看结果和二维排布。
- 套料资源支持二维缩放、平移、尺寸标注及测量，以及零件编辑、删除和型材长度编辑。
- 「新版」标签和父级橙点用于提示替换版本，已读状态保存在当前浏览器。
- 页面内的示例数据编辑和导入记录在刷新后恢复。已读记录及部分界面设置保存在浏览器本地。

## 导入 .nest 与展开图

基础示例展示可直接启动。导入 `.nest` 并生成实际展开图还需要安装、运行 RobimCut，且本机的 RobimCut MCP 服务位于 `http://127.0.0.1:7980`，提供 `generate_nest_drawing` 工具及对应 SVG 渲染模块。

`preview.py` 将本地出图请求转发到该服务。服务不可用时，导入会显示出图失败提示，支持读取的零件信息仍可用于展示。

原软件的业务后端负责真实文件解析、生产套料、正式发布等业务操作，本仓库用于界面和交互演示。

## 文件

- `index.html`、`assets/`、`css/`、`textures/` 为前端页面和运行资源。
- `preview-data.js` 提供示例数据和本地展示交互。
- `preview.py` 提供本地静态服务及 RobimCut 出图转发。
- `mock-files/production-execution/` 提供示例预览所需的数据。
- `打开本地展示.cmd` 为 Windows 启动入口。
